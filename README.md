# KPMuhurat Web — KP Muhurat Conditions Update

This GitHub Pages package adds the supplied Tamil KP Muhurat condition table to the existing browser reconstruction.

## Added
- 12 Lagna rows: Mesham through Meenam.
- Lagna lord and 11th-house lord for each row.
- Two allowed Muhurtam RL/NL/SL combinations where supplied.
- Exact RL/NL/SL matching in the Sub-level Analysis and Chosen Muhurats output.
- Tamil condition table in the Results section.
- Green highlighting for exact matches and red highlighting for non-matches.
- The source sheet's transit 6/8 restriction is documented in the UI, but is not automatically enforced because the current browser engine does not yet calculate all planetary transit longitudes.

## Publish
Upload the contents of this folder to the root of a GitHub Pages repository and enable Pages from the `main` branch/root folder.
