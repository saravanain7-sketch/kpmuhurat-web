PlaceSelect

PlaceSelect uses an embedded browser-safe city list. You can always enter coordinates manually on the Data tab. The original MSI contains a much larger place database; this static build does not claim to contain every original record.

Help

This is a browser-hosted reconstruction. Upload the files to an HTTPS static host such as GitHub Pages and open the page in Chrome.

It is not the original executable/source code. Exact calculation equivalence requires regression testing against KPMuhurat V1.5.11.
