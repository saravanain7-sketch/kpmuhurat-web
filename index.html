PlaceSelect

Place database / GPS accuracy

The original V1.5.11 extraction report records 97,875 place rows. This GitHub Pages build keeps the embedded core list and adds explicit worldwide online place search plus GPS coordinates, so you are not limited to the small built-in list. GPS latitude/longitude are used directly by the Swiss Ephemeris calculation.

For exact V1.5.11 database parity, the original extracted place database file itself must be supplied; the current reconstruction package does not contain that 97,875-row database file.

Help

This is a browser-hosted reconstruction. Upload the files to an HTTPS static host such as GitHub Pages and open the page in Chrome.

Accuracy mode: Krishnamurti ayanamsa + Placidus houses + Swiss Ephemeris. The Use My GPS Location button requests high-accuracy device coordinates and uses them directly in the chart calculation.

PlaceSelect: the embedded list is retained, and Search Worldwide can find additional places online. The original MSI extraction report records 97,875 places; exact database parity requires the original extracted database file.

This remains a reconstruction, not the original Windows source/binary. Calculation equivalence should be regression-tested against V1.5.11.
